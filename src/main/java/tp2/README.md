## Descripción

En este trabajo práctico se desarrollan ejercicios relacionados con el uso de **arreglos en Java**.

Se trabajan arreglos de datos simples, arreglos de objetos, arreglos paralelos, matrices y colecciones dinámicas.

También se aplican conceptos de programación orientada a objetos y métodos para trabajar con arreglos.

---

## Ejercicios

### Ejercicio 1 - Arreglos de números

Se genera un arreglo de números aleatorios y se realizan diferentes operaciones:

- Desplazar los elementos una posición hacia la izquierda.
- Calcular la suma de números positivos y negativos.
- Invertir el arreglo original.

---

### Ejercicio 2 - Gestión de vuelos

Se utilizan arreglos paralelos para almacenar:

- Número de vuelo.
- Estado del vuelo.

Se realizan búsquedas, conteos y reorganización de los vuelos cancelados.

---

### Ejercicio 3 - Caracteres

Se trabaja con un arreglo de caracteres para:

- Detectar caracteres repetidos.
- Buscar vocales y consonantes.
- Obtener los caracteres numéricos.
- Intercambiar caracteres según determinadas condiciones.

---

### Ejercicio 4 - Gestión de equipos

Se crea la clase `Equipo` con información sobre:

- ID del equipo.
- Nombre.
- Puntaje acumulado.
- Partidos jugados.

Se realizan operaciones para actualizar puntajes, calcular promedios y obtener el equipo líder.

---

### Ejercicio 5 - Biblioteca

Se crea la clase `Libro` para administrar una biblioteca personal.

El programa permite:

- Agregar libros.
- Buscar libros por ISBN o título.
- Modificar datos de un libro.
- Eliminar libros.
- Controlar que no se repitan los ISBN.

Para este ejercicio se utilizan colecciones dinámicas.

---

### Ejercicio 6 - Matriz de ventas

Se utiliza una matriz para almacenar las ventas de distintos vendedores durante varios días.

Se realizan cálculos de:

- Total de ventas por vendedor.
- Promedio de ventas por día.
- Venta máxima y mínima.
- Cantidad de vendedores que superan un objetivo.
- Ventas que superan el promedio de un día.
- Promedio de ventas de cada vendedor.

---

### Ejercicio 7 - Análisis de soluciones

Se analizan dos soluciones para obtener los números pares de un arreglo.

Se comparan aspectos como:

- Tamaño del arreglo resultante.
- Uso de memoria.
- Claridad del código.
- Uso de `ArrayList`.

---

### Ejercicio 8 - Gestión de empleados

Se trabaja con un arreglo de objetos `Empleado`.

El programa permite:

- Buscar un empleado por legajo.
- Mostrar su nombre.
- Encontrar el empleado con mayor sueldo.

También se analizan y corrigen errores de la solución propuesta.

---

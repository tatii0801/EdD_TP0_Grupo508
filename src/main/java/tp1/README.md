# Ejercicios

## Ejercicio 1 - Clase Cilindro

Se desarrolló una clase `Cilindro` para representar una figura geométrica tridimensional.

La clase contiene:

- Radio
- Altura

Se implementaron:

- Constructor predeterminado
- Constructor con argumentos
- Métodos para calcular el volumen
- Método para calcular el área de superficie
- Validación de valores positivos
- Getters y Setters

### Cálculos

Volumen:

```text
π * radio² * altura
```

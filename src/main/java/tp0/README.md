El objetivo de este trabajo práctico es realizar una auto-evaluación diagnóstica para medir los conocimientos previos en el desarrollo de algoritmos fundamentales y programación estructurada utilizando Java.

- Tipos de datos primitivos (`int`, `double`, `boolean`)
- Estructuras de control secuenciales
- Estructuras de decisión condicional (`if`, `else if`, `else`, `switch`)

- Operadores aritméticos, lógicos y relacionales
- Ingreso de datos por teclado mediante `Scanner`
- Generación de valores numéricos con `Random`
- Manipulación básica de cadenas con la clase `String`
- Modularización de funciones en el archivo principal
- Formateo de salidas por pantalla y consola

# 📝 Detalle de los Ejercicios

### Ejercicio 1 - Cálculo de salario neto y horas extras
Se calcula el salario neto de un trabajador en función de las horas trabajadas. El algoritmo contempla el pago de horas extras con un recargo del 50% para jornadas superiores a 40 horas y aplica descuentos de ley escalonados (9%, 12% o 15%) según el monto del salario bruto obtenido.

### Ejercicio 2 - Simulación de sensor de temperatura diario
Se modela un sistema que registra un número N de mediciones climáticas generadas aleatoriamente entre -10°C y 40°C. Al finalizar, el programa calcula el promedio diario e identifica la cantidad exacta de registros considerados "Heladas" (menores a 0°C) y "Cálidas" (mayores o iguales a 30°C).

### Ejercicio 3 - Clasificación de rendimiento académico
Se calcula el porcentaje de rendimiento de un estudiante en base a las preguntas totales de un examen y sus respuestas correctas. El sistema valida las entradas y clasifica el resultado final dentro de las categorías estipuladas: Excelente, Muy Bueno, Aprobado o Desaprobado.

### Ejercicio 4 - Calculadora de áreas geométricas modular
Se implementa un menú interactivo repetitivo utilizando estructuras condicionales para calcular el área de cuadrados, triángulos y círculos. El programa valida de manera estricta que las dimensiones ingresadas por el usuario no sean negativas.

### Ejercicio 5 - Filtrado y promedio en rangos numéricos
Se generan aleatoriamente tres valores: límite inferior, límite superior y un divisor exacto. El programa recorre el rango establecido, muestra los números que son divisibles por el tercer valor y calcula su promedio entero controlando la excepción matemática de la división por cero.

### Ejercicio 6 - Manipulación y análisis de cadenas de texto
Se solicitan los nombres de una ciudad y un país para realizar operaciones avanzadas con la clase `String`. El algoritmo une las cadenas, calcula sus longitudes por separado, determina cuál es más larga, valida la existencia del carácter "ñ" y transforma el resultado final a minúsculas.
